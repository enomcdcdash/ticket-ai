# TICKET-AI

AI-powered Telecom KPI Analytics Assistant using:
- Gemini AI
- LangChain
- ChromaDB
- Streamlit
- RAG Architecture

## Features
- Telecom KPI analysis
- Conversational AI
- Vector database retrieval
- Persistent dataset storage
- Regional operational insights

## Tech Stack
- Python
- Streamlit
- LangChain
- Gemini API
- ChromaDB
- Sentence Transformers

## Run Project

```bash
pip install -r requirements.txt
streamlit run app.py
```
